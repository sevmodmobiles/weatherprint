# Погода на принтер (Epson L805)

Android-приложение. Раз в день, когда телефон дома и видит принтер в сети, оно печатает прогноз погоды на четверть листа A4. Внизу прогноза — полоса из всех 6 цветов, чтобы дюзы не засыхали.

## Как расходуется бумага

Пачка из 30 листов проходит 8 раз, итого 240 дней.

| Проход | Сторона | Четверть |
|---|---|---|
| 1 | лицо | верх-лево |
| 2 | лицо | верх-право |
| 3 | лицо | низ-лево |
| 4 | лицо | низ-право |
| 5–8 | оборот | те же четверти |

Лист крутить не нужно: позицию сдвигает само приложение. Когда пачка закончилась, приходит уведомление:
- после проходов 1–3, 5–7 — переложить листы из выходного лотка обратно **той же стороной**;
- после прохода 4 — **перевернуть пачку** чистой стороной;
- после прохода 8 — заложить новую бумагу.

После перекладки нажмите в приложении «Бумага заложена». Пока кнопка не нажата, печать стоит на паузе.

## Сборка и установка

APK собирается автоматически в GitHub Actions при каждом push в `main` и публикуется на странице [Releases](https://github.com/sevmodmobiles/weatherprint/releases).

Установка и обновления на телефоне — через [Obtainium](https://github.com/ImranR98/Obtainium):
1. Установите Obtainium (APK со страницы его релизов на GitHub).
2. Add App → URL `https://github.com/sevmodmobiles/weatherprint` → Add.
3. Install. Дальше Obtainium сам покажет обновление после каждой новой сборки.

APK подписывается постоянным ключом `app/signing.keystore`, поэтому обновления ставятся поверх старой версии без удаления.

Ручная сборка: откройте папку в Android Studio и нажмите Run.

## Настройка

1. Будучи дома в Wi-Fi, нажмите **«Найти принтер в сети»** и выберите L805 из списка. IP вводить не нужно: если роутер выдаст принтеру новый адрес, приложение найдёт его заново по имени.
2. Приложение сразу проверит принтер. Должно появиться «JPEG поддерживается ✓».
3. Нажмите «Напечатать сейчас» — выйдет первый прогноз.
4. В настройках Android отключите для приложения оптимизацию батареи (Настройки → Приложения → Погода на принтер → Батарея → Без ограничений).

## Как это работает

- Каждые ~30 минут при Wi-Fi приложение проверяет: печатали ли сегодня, наступил ли нужный час (по умолчанию с 17:00), отвечает ли принтер.
- Если принтер ответил — телефон дома. Приложение берёт прогноз с Open-Meteo (бесплатно, без ключа; если он недоступен — с MET Norway или wttr.in) и отправляет страницу напрямую на принтер, без диалога печати.
- Принтеры с AirPrint получают страницу по IPP (порт 631). Epson без AirPrint, как L805, — на «родном» языке Epson ESC/P-R через порт 9100, так же как печатает Epson iPrint.
- Если печать не удалась (принтер выключен), счётчик не сдвигается, попытка повторится позже.

## Если не печатает

- «Принтер не отвечает» — проверьте IP; попробуйте путь `/ipp/printer` вместо `/ipp/print`.
- «JPEG НЕ найден» — пришлите список форматов, который показывает приложение, добавлю нужный формат.
- Прогноз сдвинут или обрезан — принтер по-своему масштабирует картинку; это настраивается в `PageRenderer.kt` (константа `PAD`).
